# Sales Performance Dashboard – Overview
  This dashboard was built using Power BI to explore and visualize sales trends from a fictional retail dataset. It breaks down sales by product category, region, and month, and gives a clear view of what’s selling, where, and when.

# visualization
  1.A line chart showing sales across months by category
  2.A bar chart comparing regional sales
  3.A donut chart for sales by product category
  4.Included a filter (slicer) so you can focus on specific regions.

# Tools Used
  Power BI Desktop for data visualization and interactivity
  Power Query to transform and clean the date field
  DAX to create calculated columns (e.g., "Month-Year" format)
